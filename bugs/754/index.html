Hello,
I was looking over the manual page for HTML_QuickForm::registerElementType() and noticed that at the bottom of the page, it says that you can't call this function statically. I posted a question to php.pear.general about why you cannot use this function statically, and was told that actually you *can* call this function statically, and that this is a bug in the documentation that needs to be fixed. I was told this by Alexey Borzov (borz_off@cs.msu.su), or someone claiming to be Alexey. He/she also asked that I submit a bug report so that the documentation could be fixed.

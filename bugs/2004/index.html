Description:
------------
I use QuickForm 3.2.3 and the Renderer ArraySmarty.

When I have a group of elements with an added group rule, any error message is only set on group level and not on element level.

In the Reproduce Code I entered an example how the QuickForm Renderer for Smarty works at the moment. I would like to have the error message not only on the group level mygroup => error but also on the element level mygroup => element2 => error.

I would be very glad if this could be implemented.

Reproduce code:
---------------
[mygroup] => Array
(
[name] => mygroup
[value] => Array
(
[element1] => some text
[element2] =>
)
[type] => group
[error] => Input is missing.

[element1] => Array
(
[name] => mygroup[element1]
[value] => some text
[error] =>
)

[element2] => Array
(
[name] => mygroup[element2]
[value] =>
[error] =>
)
)

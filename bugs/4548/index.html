Description:

In file Archive.php variable $_File_Archive_Options needs to be set global:

global $_File_Archive_Options;
$_File_Archive_Options = array(
'zipCompressionLevel' => 9,
'gzCompressionLevel' => 9,
'tmpDirectory' => '.',
'cache' => null,
'appendRemoveDuplicates' => false
);

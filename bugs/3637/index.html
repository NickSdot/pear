This line:

$db->limit($page['from'] - 1, $pagerOpt['perPage']);

in Pager_Wrapper.php is wrong - it refers to a non existent options array. It should read :

$db->limit($page['from'] - 1, $pager_options['perPage']);

Without this change the poager will always return all results from a query, without paging

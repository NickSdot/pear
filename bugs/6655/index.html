Description:
------------
Create String with default values for char-type columns is improperly coded.

Test script:
---------------
Just a short patch (Manager.php):

// set the "DEFAULT" portion
if ($default) {
switch ($coltype) {
case 'char':
case 'varchar':
case 'clob':
$declare .= " DEFAULT '$default'";
break;
default:
$declare .= " DEFAULT $default";
break;
}
}

Expected result:
----------------
CREATE TABLE mytable (
char_columnCHAR(2) NOT NULL DEFAULT '3I'
)

Actual result:
--------------
CREATE TABLE mytable (
char_columnCHAR(2) NOT NULL DEFAULT 3I
)

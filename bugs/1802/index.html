Description:
------------
After logging in, the getAuth()-function give always
false as return.
I got the right result, as I changed in Auth.php

function getAuth() {
if ( isset($this->session['registered']) ) {
$this->session['registered'];
}
return false;
}

to

function getAuth() {
if ( isset($this->session['registered']) ) {
return $this->session['registered'];
}
return false;
}

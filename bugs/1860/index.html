Description:
------------
The ITDynamic renderer first tries to find a block named {prefix}_{element_type} and then {prefix}_{element_name}. I would expect the order to be reversed, as an element's name is definitely more precise than it's type.

Reproduce code:
---------------
in file ITDynamic.php
---------------------
function _matchBlock(&$element)
{
[...]
if ($this->_tpl->blockExists($prefix . '_' . $type)) {
return $prefix . '_' . $type;
} elseif ($this->_tpl->blockExists($prefix . '_' . $name)) {
return $prefix . '_' . $name;
} else {
return $prefix . '_element';
}
}

replace with:
-------------
function _matchBlock(&$element)
{
[...]
if ($this->_tpl->blockExists($prefix . '_' . $name)) {
return $prefix . '_' . $name;
} elseif ($this->_tpl->blockExists($prefix . '_' . $type)) {
return $prefix . '_' . $type;
} else {
return $prefix . '_element';
}
}

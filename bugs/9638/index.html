[2006-12-16 17:42 UTC] chad dot wagner at gmail dot com

Description:
------------
Error is thrown when double calls are made to decrypt:

Reason appears to be in Crypt/Blowfish/PHP.php that keyHash is static in setKey. Moving $keyHash to a class variable appears to solve the issue.

Test script:
---------------
$key = 'blahblah';
$iv = 'halbhalb';

require_once ('Crypt/Blowfish.php');
$c =& Crypt_Blowfish::factory ('cbc', null, null, CRYPT_BLOWFISH_PHP);
$c->setKey ($key, $iv);
$val = base64_encode ($c->encrypt('cool'));
echo $val . "\n";
$c->setKey ($key, $iv);
echo $c->decrypt(base64_decode ($val)) . "\n";

$c =& Crypt_Blowfish::factory ('cbc', null, null, CRYPT_BLOWFISH_PHP);
$c->setKey ($key, $iv);
echo $c->decrypt(base64_decode ($val)) . "\n";

Expected result:
----------------
W2UjbYSOVo8=
cool
cool

Actual result:
--------------
W2UjbYSOVo8=
cool
Object

Description:
------------
http://pear.php.net/manual/en/package.database.db-dataobject.db-dataobject.query.php
says you should do a find() after a query()

After eventually realising that no matter what the query was that it was returning everything, I removed the find() and it worked.

Is this a problem with the docs or with query()/find()?

Test script:
---------------
$speaker = new DBO_Speaker;
$speaker->query("
SELECT * FROM speaker WHERE id=23
");
$speaker->find();

$array = array();

while ($speaker->fetch()) {
$array[] = clone($speaker);
}

return $array;

Expected result:
----------------
finds nothing

Actual result:
--------------

Description:
------------
First of all, I didn't get what these lines in the tutorial
do:

$text = $email->addSubPart($body, $params);
$attach =& $email->addSubPart($body, $params);

So I replaced them with

$email->addSubPart($body, $params);
$email->addSubPart($attach, $params);

As for the actual bug, Mail_Mime seems not to work
correctly with attaching e-mails as subparts. I have spent
hours comparing a forwarded message generated by KMail and
Mail_Mime and the biggest difference I noticed was the
number of linefeeds before/after headers and boundaries.
Perhaps somebody knows if that's the case? Anyway, can it
be fixed, or can I be pointed in the right direction? :)

Reproduce code:
---------------
$params['content_type'] = 'multipart/mixed';
$mime = new Mail_mimePart('', $params);

$params['content_type'] = 'multipart/mixed';
$params['disposition'] = 'inline';
$mime = new Mail_mimePart('', $params);
$params['content_type'] = 'text/plain';
$params['encoding'] = '7bit';
$params['disposition'] = 'inline';
$mime->addSubPart($body, $params);

$params['content_type'] = 'message/rfc822';
$params['encoding'] = '7bit';
$params['disposition'] = 'inline';
$params['descriptipn'] = 'forwarded message';
$email->addSubPart($attach, $params);
// $attach is an e-mail message

$_body = $mime->encode();
// add some more headers here
$body = $_body['body'];
$hdrs = $_body['headers'];

$mail =& Mail::factory('mail');

$mail->send($recipient, $hdrs, $body);

Expected result:
----------------
Something that would actually work. Neither Mail_Mime nor
KMail does decode the attached message. Mail_Mime sees the
parts of the message correctly, but can not decode the
attachment. KMail sees the attached message, but no parts
of it, and no headers, everything is rubbish.

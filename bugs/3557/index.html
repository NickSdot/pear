Description:
------------
Using a default function names xmltag_ results in Warnings

Reproduce code:
---------------
class myHandler extends XML_Parser
{
protected function xmltag ()
{
echo "start";
return true;
}

protected function xmltag_ ()
{
echo "stop";
return true;
}
}

Expected result:
----------------
No Notice :-)

Actual result:
--------------
Notice: Undefined variable: attribs in /usr/local/php/pear/XML/Parser.php on line 598

Line 598 is:
call_user_func(array(&$this->_handlerObj, 'xmltag_'), $xp, $elem, $attribs);

$attribs does not exist in this method. This line was copied from the method above

A lot of the documentation uses "it's" instead of "its". It's a simple thing to fix (a global search and replace will very likely fix most of it without introducing many of the opposite error). The rule is: "it's" is short for "it is", so if a sentence doesn't make sense with "it is" in place of "it's", then you need to use "its" instead.

This is a pretty trivial bug, really, but it's so easy to fix, it makes sense to do it anyway. Documentation with obvious grammatical errors lacks credibility.

Description:
------------
It looks like that the _boundaresplit() function splits the input on the boundaries, but the first and last part found is not returned (for $i = 1, $i < count ($tmp) -1; $i++)...)
It should not rule out any parts returned by the split. A quick solution would be to modify the line to "for $i=1; $i<=count($tmp)-1; $i++).

However, it will return the attachment but also returns a empty part which is found between "------=_NextPart_000_002C_8A6A229E.7935106B--

------=_NextPart_000_002C_932E5A3C.95C782A3".

Maybe a better solution would be to check if the last part contains text, if so, return that part, otherwise skip it.

Description:
------------
when calling oci8::modifyLimitQuery($q, 0, 1) then the query returns 2 records, instead of 1

Reproduce code:
---------------
CURRENT CODE:

$from += 1; // in Oracle rownum starts at 1
$query = "SELECT $fields FROM".
" (SELECT rownum as linenum, $fields FROM".
" ($query)".
" WHERE rownum <= ". ($from + $count) .
") WHERE linenum >= $from";

SHOULD BE:

$count += $from;
$from += 1; // in Oracle rownum starts at 1
$query = "SELECT $fields FROM".
" (SELECT rownum as linenum, $fields FROM".
" ($query)".
" WHERE rownum <= ". ($count) .
") WHERE linenum >= $from";

Description:
------------
Using buildPath() results in a number of warnings, because the delimiter of the PCRE is a / which clashes with the directory separator.

Reproduce code:
---------------
require_once('File/Util.php');
$parts=array('a','b','c');
echo File_Util::buildPath($parts);

Expected result:
----------------
a/b/c

Actual result:
--------------
Warning: preg_match() [function.preg-match]: Unknown modifier '+' in /usr/local/php/pear/File/Util.php on line 60

Warning: preg_match() [function.preg-match]: Unknown modifier '+' in /usr/local/php/pear/File/Util.php on line 60

Warning: preg_match() [function.preg-match]: Unknown modifier '+' in /usr/local/php/pear/File/Util.php on line 60
a/b/c

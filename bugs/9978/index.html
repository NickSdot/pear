Description:
------------
Using PEAR_Frontend_Web, several packages are located under the category 'Local', instead of the categories used at http://pear.php.net/packages.php.
Therefore the updates of these packages are not detected using the [list avail. upgrades] link.
When using the 'Package Search' however, the packages do appear in the proper categorie and updates are detected.
Some of the packages wich appear in the local category are:
DB, XML_RPC, HTML_QuickForm_advmultiselect, HTML_QuickForm, Net_SMTP, Pager and more

Test script:
---------------
Click on [list avail. upgrades]

Expected result:
----------------
An overview of updates for all installed packages.

Actual result:
--------------
Only updates for packages not in the 'Local' category are shown

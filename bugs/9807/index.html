Minor doc correction

In the first example (simple example) in:
http://pear.php.net/manual/en/package.caching.cache-lite.intro.php

The following is incorrect:
// (...)
$Cache_Lite->save($data);
}

What I believe the programmer meant was:
// (...)
$Cache_Lite->save($id);
}

If you leave it as it is ($data), you always hit the cache since nothing is ever saved to the cached file.

Actual result:
--------------
The cache file is generated but due to the bug nothing is ever saved to the cache file.

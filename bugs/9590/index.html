[2006-12-09 02:30 UTC] sgartner at pingbot dot com

Description:
------------
I could not find anywhere in the PEAR manual actual help on how to install PEAR modules. On the most promisingly titled page, "installation" it mentions that there is a "package manager" but gives no information on how to use it, how to run it, or where to go for more information about it.

The manual basically is focused on people who already know about PEAR and doesn't serve the community that just needs to use a PEAR module and needs help getting it installed. It's an easy enough process, but if it's not documented how can they find out.

Even Googling for "installing PEAR modules" produces marginally useful links and NONE at pear.php.net. Searching for this or similar things at pear.php.net produces mostly bug reports, which are no help at all.

I was looking for a good place to send a n00b to help them understand the process so that I wouldn't have to walk them through it myself, and I came up empty. The best one I found was at DreamHost, and it was pretty specific to them.

A sad state of affairs. Support the n00bs they are the next generation.

[2006-12-09 02:41 UTC] sgartner at pingbot dot com

I did finally find:

http://pear.php.net/manual/en/installation.cli.php

I still think it was too difficult to find by searching. Once I started going through the manual I found it quickly enough, but I had already known where the manual was, I wouldn't have even found it from searching.

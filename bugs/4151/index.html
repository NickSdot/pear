Description:
------------
When using the filter IndentStyles, PHP reports an undefined property $getSettings in the filter class. This happens even when error_reporting excludes displaying notices.

Reproduce code:
---------------
<?php
require_once('PHP/Beautifier.php');

$php = new PHP_Beautifier();
$php->addFilter('pear',array('add_header'=>'pear'));
$php->addFilter('ArrayNested');
$php->addFilter('IndentStyles',array('style'=>'Allman'));

$php->setInputFile('test.php');
$php->setOutputFile('test.php.beautified');

$php->setIndentNumber(4);

$php->process();
echo "<p>Finished</p>\n";
$php->save();
?>

----------------
<p>Finished</p>

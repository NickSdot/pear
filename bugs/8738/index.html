Description:

I tried installing PEAR both with go-pear.bat and by saving http://go-pear.org/ as gopear.php, and running php.exe gopear.php; the latter gave me better results but both ended up installing nonworking versions of pear.bat. The error I get when running pear.bat:

REM Check PEAR global ENV, set them if they do not exist

IF "%PHP_PEAR_PHP_BIN%"=="" SET "PHP_PEAR_PHP_BIN=C:\PHP5\php.exe"
GOTO :INSTALLED

Description:
------------
DB_DataObject-1.7.2

Generated DataObjects cannot be serialized using serialize. A __sleep() method is missing (is not generated).

Therefore, I have problems to use DataObjects in unit tests (assertEquals uses serialize).

Reproduce code:
---------------
<?php
require_once 'DB/DataObject.php';

class DO_Test extends DB_DataObject
{
var $__table = 'test';
var $id;

function staticGet($k,$v=NULL)
{ return DB_DataObject::staticGet('DO_Test',$k,$v); }
}

$test = new DO_Test;
serialize($test);
?>

Expected result:
----------------
-no notice, warning or error message-

Actual result:
--------------
PHP Notice: serialize(): __sleep should return an array only containing the names of instance-variables to serialize. in test.php on line 14

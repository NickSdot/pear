Description:
------------
serializer is encapsulating array nodes inside a var node without attributes

this is double wrong according to wddx official DTD (http://www.openwddx.org/downloads/dtd/wddx_dtd_10.txt) :

1) var nodes should always have an attribute name

2) var nodes are not allowed inside an array

this is not a big deal when deserializing wddx streams : both native & PEAR deserializers are smart enough

but now i am doing xslt on wddx streams it changes everything !

plus wddx streams encoded with PEAR are not valid

---

another slight difference between PEAR & native PHP wddx workaround :

native PHP is encapsulating special chars inside a string into a char node

while

PEAR is encapsulating the whole string into a CDATA section

don't know yet how to deal with it, so far i think i can handle it both ways

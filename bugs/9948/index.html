Description:
------------
Although the package.xml file for the package describes the license with a URL, including a copy of the exact license under which the package is licensed would be very much appreciated by downstream packagers, so that end users can easily access this information.

Specifically, Console_Color has been packaged for Fedora Extras, and in general we like to include a copy of the license for packages we use. Whilst we could pull in a copy from the URL you referenced, it is useful to other users who might download a tarball of your package to be able to have a copy of the license to hand. It ensures that the license is available offline, that there is no ambiguity about it and that if you make changes to the licensing, we do not inadvertently include an incorrect license.

See:
http://bugzilla.redhat.com/bugzilla/show_bug.cgi?id=224413 for the review ticket related to this package in Fedora Extras.

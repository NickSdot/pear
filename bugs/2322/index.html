Original code in median():

$n = count($arr);
$h = intval($n / 2);
if ($n % 2 == 0) {
$median = ($arr[$h] + $arr[$h - 1]) / 2;
} else {
$median = $arr[$h + 1]; // <--- HERE
}

I believe the line should read

$median = $arr[$h];

For example, n=5, h=intval(2.5), h=2
We are interested in the 3rd element of an array, it's index is 2.

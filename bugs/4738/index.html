On Debian (and perhaps other 'Debian-based' systems - e.g., Ubuntu) PEAR is not available on the command-line as is mentioned here in the doc page. Instead, one must first install the 'php4-pear' package. For example:

# apt-get install php4-pear

now you can issue PEAR commands:

# pear remote-list

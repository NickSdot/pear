Description:
------------
Testing the 0.8.1 release caused a parse error in the evaluated code of the generated proxyclass. The WSDL used was the eCommerce Service Version 4 of Amazon.de (ECS4).

Detailed information about ECS4 can be obtained under http://webservices.amazon.com/

Reproduce code:
---------------
<?php
require_once('SOAP/Client.php');

$wsdl = 'http://webservices.amazon.com/AWSECommerceService/US/AWSECommerceService.wsdl';
$proxyParams = array(
'proxy_host' => 'define.proxy.here.com',
'proxy_port' => 3128,
);

$wsdl = new SOAP_WSDL($wsdl, $proxyParams);
$proxy = $wsdl->getProxy();

?>

Expected result:
----------------
A valid proxyclass.

Actual result:
--------------
Parse error: syntax error, unexpected ':', expecting ')' in C:\Programme\php5\PEAR\SOAP\WSDL.php(614) : eval()'d code on line 259

Fatal error: Class 'WebService_AWSECommerceService_AWSECommerceServicePort' not found in C:\Programme\php5\PEAR\SOAP\WSDL.php on line 617

[2005-12-02 13:59 UTC] cm at data-consult dot de

this is the same error mentioned here:
http://pear.php.net/bugs/4585

problem is a space in the header for boundary
so boundary looks like this:

[boundary ] = fdshdfsdfhdfsksfdsdfhkj

i added some trims to the code to fix this:

line 235 change
$return->ctype_parameters[$p_name] = $p_value;
to
$return->ctype_parameters[trim($p_name)] = trim($p_value);

line 393:
$hdr_name = substr($value, 0, $pos = strpos($value, ':'));
to
$hdr_name = trim(substr($value, 0, $pos = strpos($value, ':')));

line 442:
$return['other'][$param_name] = $param_value;
to
$return['other'][trim($param_name)] = trim($param_value);

i hope i dont missed anything, but this works for me.

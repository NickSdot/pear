Using the latest release, DB_DataObject is ignoring columns with UNIQUE constraints. I'm getting it with setFrom(). If a column has a UNIQUE constraint, it will not be set via setFrom and subsequently not included in an insert/update query. This was discussed on pear-general in July, but apparently not ever submitted as a bug(?)

Running postgres 7.5 alpha on WinXP SP1, Apache 2.0.50, and PHP 4.3.8.

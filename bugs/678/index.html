Description:
------------
The search doesn't appreciate much a fully qualified host name (ending by '.')...

Reproduce code:
---------------

$dnsr = new Net_DNS_Resolver();

$dnsr->search('4.3.2.1.dnsbl.sorbs.net.');
?>

----------------
it should world like this:
<?php
require_once 'Net/DNS.php';
$dnsr = new Net_DNS_Resolver();

$dnsr->search('4.3.2.1.dnsbl.sorbs.net');
?>

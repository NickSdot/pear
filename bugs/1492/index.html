To get PEAR:SOAP to work in PHP 5 I had to make the following change in Client.php:

function &__call($method, &$args, &$return_value)

Change to:

function &__call($method, &$args, &$return_value = '')

It seems PHP5 doesn't use the return value var? I don't know. It just works now. :)

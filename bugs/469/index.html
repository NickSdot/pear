Description:
------------
If you will use the function "weekOfYear" to get the week of the current date without passing arguments, you need to modify Calc.php because of wrong defined default values.

It must be:
function weekOfYear($day="",$month="",$year="")

Instead of:
function weekOfYear($day,$month,$year)

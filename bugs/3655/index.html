Description:
------------
Missed a return statement in deleteDefaultPref() method on line 355. This causes to use deletePref('__default__', $pref_id) instead of deleteDefaultPref() method.

Reproduce code:
---------------
The code below taken from PrefManager.php file.

function deleteDefaultPref($pref_id)
{
$this->deletePref($this->_defaultUser, $pref_id);
}

should be

function deleteDefaultPref($pref_id)
{
return $this->deletePref($this->_defaultUser, $pref_id);
}

\000 is detected as a backref to itself

Null needs the \ preceding it escapped to be passed to a preg_* function.

Test script:
---------------
NULL_A = /\000/
NULL_B = /\x00/

Expected result:
----------------
NULL_A = "/\\000/"
NULL_B = "/\\x00/"

Actual result:
--------------
NULL_A = "/\1/"
NULL_B = "/\x00/"

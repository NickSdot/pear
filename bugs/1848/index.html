from http://pear.php.net/manual/en/developers.packagedef.php:

The toplevel element in package.xml is the element <package version="1.0">. The allowed sub elements are:

[...]

<deps>: List of dependencies of the package.

While the DTD states:

<!ELEMENT package (name|summary|description|license|maintainers|release|changelog)>
<!ELEMENT release (version|license|state|date|notes|filelist|deps)*>

So I guess the docs are incorrect, in fact looking at existing package.xml files (eg for DB), <deps> is a sub-element of <release>

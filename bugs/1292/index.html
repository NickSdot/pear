[2004-05-19 17:54 UTC] thierry dot bo at netcourrier dot com

Well, now I can't reproduce the problem, instead but it fails whatever option I choose. This is with 1.3, not cvs. The problem is at the begining of fetchCol() in common.php:

function fetchCol($result, $colnum = 0)
{
$fetchmode = is_numeric($colnum) ? MDB_FETCHMODE_ORDERED : MDB_FETCHMODE_ASSOC;
$column = array();
$row = $this->fetchInto($result, $fetchmode);
if (is_array($row)) {
if (!array_key_exists($colnum, $row)) {
return($this->raiseError(MDB_ERROR_TRUNCATED));
}

If optimize is set to 'portability', $colnum == 'Key_name' and keys in $row are lowercased ('key_name'), so this raise error MDB_ERROR_TRUNCATED.

If optimize is set to 'performance', $colnum == 'key_name' but keys in $row are left unchanged ('Key_name'), so this also raise error MDB_ERROR_TRUNCATED.

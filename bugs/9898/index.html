"Example 34-3. Passing an array to execute()" in online documentation as of 2007-01-21 has reference to an unused variable "$types" which may confuse people:

// Current documentation:

// Once you have a valid MDB2 object named $mdb2...
$types = array('integer', 'text', 'text');
$sth = $mdb2->prepare('INSERT INTO numbers VALUES (:id, :text, :lang)');

$data = array('id' => 1, 'name' => 'one', 'lang' => 'en');
$affectedRows = $sth->execute($data);

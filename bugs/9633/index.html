Description:
------------
When I import my XML doc into multi dimensional array, sinlge element index is not leveled as multiple elements indexes.

For example, in my XML, I have a single element as:
<subitems>
<msulabel>Index Page</msulabel>
<msufilename>index.php</msufilename>
</subitems>

this will generate an array without an index key, but when I have multiple elements as:

<subitems>
<msulabel>My Info</msulabel>
<msufilename>my_info.php?mm_id=6</msufilename>
</subitems>
<subitems>
<msulabel>My Login</msulabel>
<msufilename>my_login.php?mm_id=6</msufilename>
</subitems>

this will generate multiple index keys. The problem is that when I am building my array to export, it looks fine, but when I import, original first index (0) for a single array, it won't show up.

This cause a problem for me when I use foreach or while loops, because, loop expect a multi dimensional array.

Thank you.
Nizzy

Test script:
---------------
$unserializer = &new XML_Unserializer();
$unserializer->unserialize($xmldoc, true);
$menu_arr = $unserializer->getUnserializedData();

Using MySQL, if I have a query like:

SELECT option FROM table1

No error is reported by the MDB MySQL driver that I could see... (I tried a var_dump of the object as well as checking the getMessage method). The only thing that MySQL reports is:

#1064 - You have an error in your SQL syntax. Check the manual that corresponds to your MySQL server version for the right syntax to use near 'OPTION FROM table1' at line 1

Since OPTION is a key word, that would be expected, and if I put OPTION between back ticks, the error is resolved (for MySQL anyway).

MDB needs to have an auto-delimiting feature for queries. MDB2 already has quiteIdentifer() (as reported from Lukas) that should be added to MDB.

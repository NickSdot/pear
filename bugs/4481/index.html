[2005-10-16 16:50 UTC] mbretter at php dot net

You must invoke:
start()
before you can put attributes:
$racct = new Auth_RADIUS_Acct_Stop;
$racct->addServer($server, 0, $shared);
$status = $racct->start();
$racct->putAttribute(RADIUS_USER_NAME,$username);

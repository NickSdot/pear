The dateOptions callback method (and possibly others) seem to be broken with the latest update (0.18.0)

When I implement the callback method in my DO, it never gets called because the "is_callable" function from "QuickForm.php"'s "_createDateElement" method returns false due to the first parameter in the array being empty.

The problem appears to be in the DB_DataObject_FormBuilder constructor when "$this->dateOptionsCallback" is being set.

$this->dateOptionsCallback= array(&$this->_fb->_do, 'dateOptions');

Changing it to this:

$this->dateOptionsCallback = array(&$do, 'dateOptions');

makes it work, since "&$this->_fb->_do" appears empty.

Description:
------------
The Argument Id seems to get lost when calling GetItem

Reproduce code:
---------------
require_once ('Services/Ebay.php');
require_once('auth2.inc.php');

try
{
$session = Services_Ebay::getSession($devId,
$appId,$certId);
$session->setToken($token);

$getItem= Services_Ebay::loadAPICall('GetItem');
$getItem->DetailLevel=2;
$getItem->DescFormat=1;
$getItem->ErrorLevel=1;
$getItem->Id='4502213532';
$erg=$getItem->call($session);

}
catch (Exception $error)
{
die ("Error: ".$error->getMessage());
}

Expected result:
----------------
Valid Item object

Actual result:
--------------
No <Id> exists or <Id> is specified as an empty tag in the XML request.

The XML request is:
<request xmlns="urn:eBayAPIschema">
<DetailLevel>0</DetailLevel>
<ErrorLevel>1</ErrorLevel>
<SiteId>0</SiteId>
<Verb>GetItem</Verb>
<RequestToken>AA**/* complete Token */AEyxc</RequestToken>
</request>

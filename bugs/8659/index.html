Description:
------------
when using mail_queue with mdb2 container and sqlite I could not get get() to work. It would always return false. I traced the problem all the way to line 863 of the mdb2 sqlite driver:

$row = @sqlite_fetch_array($this->result, SQLITE_ASSOC);

$row was empty, so I removed the '@' and it through an error:

Warning: sqlite_fetch_array() expects parameter 1 to be resource, object given in C:\system_data\websites\customers\zeydel\lib\PEAR\MDB2\Driver\sqlite.php on line 863

I am not sure who's bug this is, but I am starting with you.

FYI, I used my same code with the DB container and it worked fine.

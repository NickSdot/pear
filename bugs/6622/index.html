Description:
------------
The French documentation page has a major encoding problem.
The original file is encoded in UTF-8 and the page has no
correct encoding set.

Test script:
---------------
You should modify all your pages header like following :

Complete the html tag with the xml:lang attribute.

Add a meta content-type that describes the used encoding set.

In addition in order to getting prepared to a full CSS layout you might also :

Suppress the xml declaration that may cause IE to switch to quirksmode.

Change the doctype to strict instead of transitional unless you have tags that justify it (also mostly for IE 6).

Expected result:
----------------
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="fr">
<head>
<meta http-equiv="content-type" content="text/html;
charset=utf-8" />

Actual result:
--------------
<?xml version="1.0" encoding="iso-8859-1" ?>
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">
<html>
<head>

[2006-09-23 15:13 UTC] fdelaneau at mac dot com

Even without speaking french you could easily notice the
problem: Every accents are replaced by a symbol. In Safari it
can't be missed, a black losange with a white questionmark.
Firefox is a little more sober and only displays a black
questionmark.

And no this ISO format doesn't allows the native use of
accents, only UTF does, so : é è ç à will be displayed broken
unless encoded é &eagrave; ç à

Description:
------------
When calling a web service which can return multiple XML elements with the same name, an array is returned rather than an object.

For example the xml response below is incorrectly decoded
<book>
<author>Bob</author>
<author>Sue</author>
<title>My Book</title>
</book>

Test script:
---------------
Patch:
Base.php, Line 905
//$return = array($return->{$item->name}, $d); $return->{$item->name} = array($return->{$item->name}, $d);

Test Script:
<?php

require_once 'SOAP/Client.php';

$wsdl_url =
'http://webservices.amazon.com/AWSECommerceService/AWSECommerceService.wsdl';
$WSDL = new SOAP_WSDL($wsdl_url);
$client = $WSDL->getProxy();

$params = array(
'SearchIndex' => 'Books',
'Power' => 'asin: 1592289800',
'Sort' => 'salesrank',
'ResponseGroup' => 'ItemAttributes',
'AWSAccessKeyId' => 'XXXXXXXXXXXXXX',
'AssociateTag' => 'XXXXX-20',
'Version' => '2006-11-14'
);

echo("<pre>");
print_r($client->ItemSearch($params));
echo("</pre>");

?>

[Item] => stdClass Object

This seems to work for that. Probably needs some testing and modifications.

$regex = '/[^\x00-\x20()<>@,;:\\".[\]\x7f-\xff]+
(?:\.[^\x00-\x20()<>@,;:\\".[\]\x7f-\xff]+)*\@
[^\x00-\x20()<>@,;:\\".[\]\x7f-\xff]+
(?:\.[^\x00-\x20()<>@,;:\\".[\]\x7f-\xff]+)+/i';

(added some newlines so it doesn't kill page layout)

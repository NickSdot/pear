I guess there's a bug in the package-1.0 DTD, the declaration for the package element is missing a +:

<!ELEMENT package (name|summary|description|license|maintainers|release|changelog)>

should be

<!ELEMENT package (name|summary|description|license|maintainers|release|changelog)+>

not sure if this goes in the Documentation category.....

[2004-07-12 09:27 UTC] ludoo at php dot net

a simple check:

- get the DB package.xml file
- add a DTD declaration to it pointing to the package-1.0 dtd

- run xmllint --noout --valid package.xml

- observe lots of errors scroll by, the last one being:

package.xml:166: element package: validity error : Element package content does not follow the DTD, expecting (name | summary | description | license | maintainers | release | changelog), got (name summary description license maintainers release )

simple fix: allow more than one child in the package element:
<!ELEMENT package (name|summary|description|license|maintainers|release|changelog)+>

xmllint --noout --valid package.xml now gives lots of errors for missing attribute declarations, but the package element error is gone

a better fix would be something like this:

<!ELEMENT package (name,summary,description,license,maintainers,release+,changelog*)>

What's the use of a dtd if:

a) it does not work
b) nobody verifies their package.xml with it

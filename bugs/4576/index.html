Description:
------------
in the code example on page

http://pear.php.net/manual/en/package.console.console-getopt.readphpargv.php

near the bottom of the page is example code
that demonstrates Console_Getopt->readPHPArgv().

it then uses Console_Getopt->getopt() but
it *should* be calling Console_Getopt->getopt2(),
because of the preceding array_shift() call on
the $argv array.

I am ashamed to admit this took me a couple hours to
figure this out. I had to read the source code,
which was excellent documentation in itself.

thanks for all the hard work,

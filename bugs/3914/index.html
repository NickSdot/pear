Description:
------------
The decorator does not cache upon prefetch, as the get()
method wrongly calls the getRawPage() instead of
getPage().

Changing the code fixes this problem.

Reproduce code:
---------------
function get() {
...

if ($this->prefetch) {
$this->getRawPage($pageID, $langID);
}

to

if ($this->prefetch) {
$this->getPage($pageID, $langID);
}

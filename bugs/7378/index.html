[2006-04-12 10:33 UTC] pear at yellowsunshine dot de

Description:
------------
Trying to set an default/constant value for an weekday-select (quickform type date, format l) it sets the selected option always to thursday.

As far I tryed, other date types seems working correct.

Test script:
---------------
$form =& new html_QuickForm('timer', 'post', 'test.php');
(...)
$elem =& $form->createElement('date', 'weekly', 'weekly', array('format' => 'l'));
$form->addElement($elem);
$form->setConstants(array('weekly' => 1));
(...)
echo $form->toHTML();

Expected result:
----------------
<td align="right" valign="top"><b>weekly</b></td>
<td align="left" valign="top"><select name="weekly[l]"><option value="0">Sunday</option><option value="1" selected="selected">Monday</option><option value="2">Tuesday</option><option value="3">Wednesday</option><option value="4">Thursday</option><option value="5">Friday</option><option value="6">Saturday</option></select></td>

Actual result:
--------------
<td align="right" valign="top"><b>weekly</b></td>
<td align="left" valign="top"><select name="weekly[l]"><option value="0">Sunday</option><option value="1">Monday</option><option value="2">Tuesday</option><option value="3">Wednesday</option><option value="4" selected="selected">Thursday</option><option value="5">Friday</option><option value="6">Saturday</option></select></td>

[2006-04-12 11:15 UTC] mansion at php dot net

use $form->setConstants(array('weekly' => array('l' => 1)))

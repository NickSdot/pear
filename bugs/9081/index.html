Description:
------------
A call to dropDatabase() returns MDB2_Ok but the database is not dropped.

Test script:
---------------
$mdb2->loadModule('Manager');
$this->assertFalse(PEAR::isError($mdb2));
$this->assertTrue(in_array($new_db_name, $mdb2->listDatabases()));
// Drop DB
$this->assertTrue(MDB2_OK == $mdb2->dropDatabase($new_db_name));
$this->assertFalse(in_array($new_db_name, $mdb2->listDatabases()));

Expected result:
----------------
The last instruction should return false but returns true (the DB is still in the list reported by listDatabases().

DB user permission are Ok and the DB is really still there.

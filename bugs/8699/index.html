We implemented the patch from http://pear.php.net/bugs/6229 earlier in Seagull PHP Framework and improved the regex:

Currently it's:

'=(<CR>|<LF>|0x0A/%0A|0x0D/%0D|\\n|\\r).*='

We have:

"#((<CR>|<LF>|0x0A/%0A|0x0D/%0D|\\n|\\r)\S).*#i"

which would also match on <lf>

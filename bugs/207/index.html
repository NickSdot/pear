Description:
------------
As of version 1.4, ABNAMRO OfficeNet no longer accepts 1002 'Unchecked/unclean' records. Upon importing, the GIRO and BANK transactions are split up. All the BANK transactions are marked as denied.

The Clieop03 class found with this package only supports 0000 (payment) and 1002 (incasso) records. However, for succesful use with ABNAMRO OfficeNet, the class should use 1001.

For more information about the Clieop03 specification, please refer to: http://www.interpay.nl/scripts/download2.asp?file=pdf/ClieOp%2003%20januari%202003.pdf&action=download

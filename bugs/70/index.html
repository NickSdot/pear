Description:
------------
PROBLEM:
The Flexy renderer does not handle labels correctly if it is an array.

WORKAROUND:

subclass HTML_QuickForm_Renderer_ObjectFlexy::_elementToObject and do something like:

if (is_array($label)) {
$element->setLabel($label[0]);
$ret = parent::_elementToObject($element, $required, $error);
$ret->label_1 = $label[1];
$ret->label_2 = $label[2];
$ret->label_3 = $label[3];
} else {
$ret = parent::_elementToObject($element, $required, $error);
}

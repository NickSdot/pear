Description:
------------
while going thru the documentation of PEAR_ErrorStack
http://pear.php.net/manual/en/core.pear.pear-errorstack.intro.php

in the second example an error stack is being setup for
the internal db package using the methodcall

// use the callback
$dbstack->setDefaultCallback(array(&$myobj, 'errorCallback'))

this is incorrect since looking at the documentation of the above method
http://pear.php.net/manual/en/core.pear.pear-errorstack.setdefaultcallback.php

it mentions clearly "PEAR_ErrorStack::setDefaultCallback() -- Sets a default callback to be used by all error stacks"

hence the callback will be for all error stacks and not only for dbstack.

and secondly it is bad coding style to use an object to call a static method.

"Note
This function should be called statically."

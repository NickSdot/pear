Description:
------------
How do I get anonymous CVS access to PEAR source? How do I install a package from CVS into my repository?

Execute these commands:

cvs -d :pserver:cvsread@cvs.php.net:/repository login (phpfi as password)
cvs -d :pserver:cvsread@cvs.php.net:/repository co pear/Full_Pear_PackageName

[Replace Full_Pear_PackageName with the name of the package you want to check out.]

Then, to install the package from CVS into your pear repository, cd to the package's directory and do:

pear package

Or, some packages may include a package.sh or package.bat, which you can run.

Then you can just do either:

pear install Full_Pear_PackageName-X.X.X.tgz

or

pear upgrade Full_Pear_PackageName-X.X.X.tgz

(that tgz filename may differ with only a 2 digit version number)

WARNING: It is highly NOT recommended to install packages from CVS on to a production server!

Description:
------------
XML_RPC_encode() of RPC.php line 2042 should be changed to

if ($GLOBALS['XML_RPC_func_ereg']('([0-9]{4})(-([0-9]{2})(-
([0-9]{2})(T([0-9]{2}):([0-9]{2})(:([0-9]{2})(\.([0-9]+))?)?
(Z|(([-+])([0-9]{2}):([0-9]{2})))?)?)?)?$', $php_val)) {

to match ALL types of iso8601 dates. The existing expression
only matches one variety of iso8601 date.

[2007-02-26 17:51 UTC] bvogel at vt dot edu

Where in the specification http://www.xmlrpc.com/spec does it
say that only one of the iso8601 formats can be used? There is
an example given in one iso8601 format, but nowhere does it
say other iso8601 formats can't be used. See http://
en.wikipedia.org/wiki/ISO_8601 for links to the full
specification.

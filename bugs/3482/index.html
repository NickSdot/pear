Using setVersion(8) causes merge fields to go wacky.
Without it, things look fine but my fields get truncated
to the 255 character limit. With it, it looks fine in
Excel but when importing it into Word 2004 for Mac, the
fields names show up as "AutoMergeField"
"AutoMergeField1" "AutoMergeField2" etc. Shorter fields
look okay, although they have the wrong name.

Simply opening the file in Excel 2004 and clicking Save
before doing the mailmerge fixes the problem.

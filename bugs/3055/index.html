$do1->selectAs(array('id'), 'product_%s', 'product');

----------------
1. In debug mode query is:
SELECT product_reward.* , product.id AS product_id , photo.title AS photo_title , photo.filename AS photo_filename FROM ...

Actual result:
--------------
1. In debug mode query is:

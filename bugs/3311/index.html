Hi, I reproduced the bug. try it.
Actually, the sourcecode of Net_POP3::login() returns PEAR_Error (See: line 256 and line 264 of POP3.php).

<?php
require_once("Net/POP3.php");
$pop3 = new Net_POP3;
$res = $pop3->connect('your.pop3.server');
$res = $pop3->login('your_account', 'wrong_password');
if (PEAR::isError($res)) {
echo 'Net_POP3::login() returned PEAR_Error!';
}
else {
echo 'This Bug report is BOGUS!';
}
?>

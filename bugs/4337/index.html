Here is my external fix to take care of this problem:
// Page nav links
$links = $pager->getLinks();

foreach(array_keys($links) as $key)
{
$links[$key]=preg_replace('/\[/', "%5B", $links[$key]);
$links[$key]=preg_replace('/\]/', "%5D", $links[$key]);
$links[$key]=preg_replace('/\+/', "%2B", $links[$key]);
}

After my original submission I realized I needed two more lines to correct the first and last links in the array that have brackets around the page numbers. This is such a dirty hack. :)

// Page nav links
$links = $pager->getLinks();

foreach(array_keys($links) as $key) {
$links[$key]=preg_replace('/\[/', "%5B", $links[$key]);
$links[$key]=preg_replace('/\]/', "%5D", $links[$key]);
$links[$key]=preg_replace('/\+/', "%2B", $links[$key]);
$links[$key]=preg_replace('/\>\%5B/', ">[", $links[$key]);
$links[$key]=preg_replace('/\%5D\</', "]<", $links[$key]);
}

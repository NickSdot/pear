Description:
------------
The elements define with "fb_preDefElements" on third level subform return null value on submit.

Test script:
---------------
[...]
function insert() {
print_r($this->toArray());
return parent::insert();
}
function preGenerateForm(&$fb)
{
require_once 'HTML/QuickForm.php';
$this->fb_preDefElements['test'] = &HTML_QuickForm::createElement('date', 'dateTest', 'test', array('format'=>'dmY', 'minYear'=>2010, 'maxYear'=>2001));
}
[...]

Expected result:
----------------
On submit :

Array
(
[dateTest] =>
[other_field_1] => 'so good'
[other_field_2] => 'yes'
[other_field_3] => 'cool'
)

Actual result:
--------------
On submit :

Array
(
[dateTest] => '2005-10-08'
[other_field_1] => 'so good'
[other_field_2] => 'yes'
[other_field_3] => 'cool'
)

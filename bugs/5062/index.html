Description:
------------
Any occurrence of '=' within the text or the tags of the HTML body are transformed into '=3D'.

Test script:
---------------
$message = '= centered =';

$mime = new Mail_mime("\n");
$mime->setHTMLBody( $message );

echo $mime->get();

Expected result:
----------------
= centered =

Actual result:
--------------
=3D centered =3D

Description:
------------
When using this datasource driver I get an error message from DB/DataObject.

Test script:
---------------
/* Instantiate */
$dataobject = new DataObject_Fruits();
$datagrid =& new Structures_DataGrid(10);

/* Bind */
$bound = $datagrid->bind($dataobject);

Expected result:
----------------
A table with by data.

Actual result:
--------------
Notice: Undefined offset: 0 in /usr/share/pear/DB/DataObject.php on line 1512
DB_DataObject Error: You cannot do run count without keys - use $do->keys('id');

Fixed this error by adding:
$this->_dataobject->keys('id');
to line 294 in DataSource/DataObject.php

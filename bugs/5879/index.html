Description:
------------
Nested lists yield incorrect output. In stable, nested lists are not parsed properly. In CVS, they are not parsed at all.

Test script:
---------------
require('Text/Wiki.php');

$wiki = new Text_Wiki();

echo "<html>\n";
echo "<head><title>Wiki List Test</title></head>\n";
echo "<body>\n\n";

$text = <<<EOQ

* U1-1
# O2-1
# O2-2
* U1-2
* U1-3

Expected result:
----------------
<ul>
<li>U1-1
<ol>
<li>O2-1</li>
<li>O2-2</li>
</ol>
</li>
<li>U1-2</li>
<li>U1-3</li>
</ul>

Actual result:
--------------
<ul>
<li>U1-1</li>
</ul>

<p># O2-1<br />
# O2-2</p>

<ul>
<li>U1-2</li>
<li>U1-3</li>
</ul>

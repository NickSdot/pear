I think it would be very useful if you would have a link to the PhpDocumentor documentation for all packages.

The documentation is often in a howto format, for instance I had some problems using mysqli and sockets (of course it just didn't work and the latest release has fixed that) and I had to trawl around in the code to try and figure it out.

It would be much better if, like the java apis at sun, you could access the list of functions, their parameters etc online. It would also automate the online documentation of many packages, especially sub packages like the mysqli interface to the DB package.

Inline documentation is much more likely to be maintained and available than seperate documentation. I think the seperate documentation is always useful, but let it stick to extra help and have all the more minor functions done automatically.

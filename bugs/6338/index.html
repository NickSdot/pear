Description:
------------
In querystring with arrays is wrong parsing.

Test script:
---------------
$url = new Net_URL('http://localhost/run.php?a[0]=foo0&a[1]=foo1&b=foo2');
print_r($url->querystring);

Expected result:
----------------
(
[a] => array(
[0] => foo0
[1] => foo1
)
[b] => foo2
)

Actual result:
--------------
(
[a[0]] => foo0
[a[1]] => foo1
[b] => foo2
)

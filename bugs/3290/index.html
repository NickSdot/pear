[2005-01-25 06:20 UTC] kubo at isite dot co dot jp

Description:
------------
DB_QueryTool_Query::getCount() method return zero when using offset.
At least MySQL and PostgreSQL return empty set using the query as follows.

MySQL:
SELECT
COUNT(*)
FROM
person
LIMIT 25, 25
;

PostgreSQL:
SELECT
COUNT(*)
FROM
person
LIMIT 25
OFFSET 25
;

However if the offset is 0, MySQL and PostgreSQL return correct count of the query.

MySQL:
SELECT
COUNT(*)
FROM
person
LIMIT 0, 25
;

PostgreSQL:
SELECT
COUNT(*)
FROM
person
LIMIT 25
OFFSET 0
;

I hope that getCount() method always return correct count regardless of offset value.

Reproduce code:
---------------
I wrote ad hoc patches.

o MDB_QueryTool

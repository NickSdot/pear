Description:
------------
If you type [[image img.png]] (two spaces between image an d img.png) you get an empty src attribute.

Reproduce code:
---------------
The solution:
Change line 67 of parse/Image.php from
$pos = strpos($matches[2], ' ');
to
$pos = strpos(trim($matches[2]), ' ');

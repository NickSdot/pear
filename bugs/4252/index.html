[2005-05-01 05:10 UTC] johis184 at student dot otago dot ac dot nz

Description:
------------
http://pear.php.net/manual/en/package.html.html-quickform.html-quickform-renderer-itdynamic.php

Under 'Template structure' the example template does not contain the required tag for expected rendering of element labels.

<!-- BEGIN qf_group_element -->{qf_separator}{qf_element}<!-- END qf_group_element -->

should be:

<!-- BEGIN qf_group_element -->{qf_separator}{qf_label}{qf_element}<!-- END qf_group_element -->

Hopefully the code below works and provides an example of where this happens :) This is a pretty breif bug report but then its a pretty trivial problem/fix, just very annoying if you are wondering why group element labels are not being rendered and have worked off the example.

Reproduce code:
---------------
$form = new HTML_Quickform('login', 'POST', $_SERVER['PHP_SELF']);
$tmp[] =& HTML_Quickform::createElement('text', 'username',
'Username:', array('size'=>'22',maxlength=>'20'));
$tmp[] =& HTML_Quickform::createElement('text', 'password',
'Password:', array('size'=>'22',maxlength=>'20'));
$form->addGroup($tmp, 'login', 'Login:', ' ', false);
$template = new HTML_Template_Sigma('pathtotemplatedir');
$template->loadTemplatefile('pathtotemplate');
$renderer =& new HTML_QuickForm_Renderer_ITDynamic($template);
$form->accept($renderer);
$template->show();

Expected result:
----------------
Element labels.

Actual result:
--------------
No element labels.

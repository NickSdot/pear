Hi Axis_Logarithmic::setAxisIntersection() is not able to
be used with 'max'. That's because of

function Axis_Logarithmic::_intersectPoint($value)
{
if ($value <= 0) {
$value = 1;
}
return parent::_intersectPoint($value);
}

If I understand it correctly, a valid value for $value
should be 'max', but ('max' <= 0) === true.

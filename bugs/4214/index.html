Description:
------------
The DB_DataObject documentation is confusing because the
author sometimes uses the term "row" when he means to use
"column". For instance, on the getLink() page of the docs,
he uses the identifier "row" in the synopsis when he
really should have used "column":

mixed $DB_DataObject->getLink (string $row [, string
$table [, string $key]])

He again refers to columns as rows in the description of
that page:

You may also use this with all parameters to specify,
the row, and related table and row.

Similar problems exist elsewhere in the documentation,
including
http://pear.php.net/manual/en/package.database.db-dataobject.intro-relations.php
and
http://pear.php.net/manual/en/package.database.db-dataobject.db-dataobject.getlinks.php

I do have an understanding of the author's intentions now,
but these errors made it take longer than it should have
to reach it. :)

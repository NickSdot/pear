Incorrect about distributions of PHP with Pear

Description:
------------
I noticed that in your documentation
about installing pear, you say if
anyone has PHP >= 4.3.0, they already have
Pear's installer, on windows.. This is untrue..
If you check PHP's website in the list of PHP
distributions, 4.3.1, which is one of the most
popular distributions of PHP, does not have the
pear distribution with it..

I think the documentation should change to reflect
this, so that people with 4.3.1 don't get the wrong
idea..

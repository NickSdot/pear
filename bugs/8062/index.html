Documentation says to "create a directory that is NOT in your publicly accessible web space, and name it anything you'd like. Set it to be readable and writable by any user (permissions 0777)." It then instructs user to install PEAR to this directory: "When asked where to install PEAR, choose the directory you created to be readable and writable by any user".

A couple of steps later, it says, "After PEAR has been installed, you can use the web installer to install and upgrade packages just as you would with any other PEAR installation." However, if the web installer has been installed in a directory that is "NOT in your publicly accessible web space", how is one to navigate to it in order to use it?

This is either not possible, or simply unclear.

In the example of PEAR Mail_mimePart::addsubpart()
in "Example 44-1. Add two attachments to a mail"
the line to add the second attachment uses the
wrong variable name ($body) instead of ($attach).

wrong line (in example documentation):
$attach =& $email->addSubPart($body, $params);

should be:
$attach =& $email->addSubPart($attach, $params);
or:
$dummy =& $email->addSubPart($attach, $params);

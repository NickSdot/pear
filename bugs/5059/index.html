I´m using the LiveUser_Admin Version 0.3.2 and wanted to test the alias array by changing the "auth_user_id" in the liveuser_users table to "user_id". So i made the alias entry "'auth_user_id' => 'user_id'" and renamed the table column.
Then i started the admin "example 1" and chose the User link to automatically create some user data. The inserts work as aspected but when it comes to listing the existing users an error appeared:

DB Error: no such field-SELECT auth_user_id, handle, passwd, name, email FROM liveuser_users [nativecode=1054 ** Unknown column 'auth_user_id' in 'field list']

So it seems that the getUsers() or other user selecting funktion simply ignores the alias definitions because it´s still looking for the "auth_user_id" although i aliased it to be "user_id".

Description:
------------
For example, in MySQL,`tablename` should be seen as an identifier.

Reproduce code:
---------------
MySQL sql:

INSERT INTO `mpn_4nstats_datecnt` VALUES ('18042004',571);

Actual result:
--------------
Parse error: Expected table name on line 2
INSERT INTO `mpn_4nstats_datecnt` VALUES ('18042004',571);
^ found: "`"

[2004-02-17 17:20 UTC] louis at 6internet dot com

Description:
------------
The short PHP script under Reproduce Code making use of mimeDecode.php correctly returns both the body and attachment of a MIME encoded email for PHP 4.3.1 and earlier. However, the script fails to extract the attachment and only returns the body for PHP 4.3.2 and newer, but reports no error message.

I've downloaded and compiled a lot of PHP versions to discover that 4.3.1 -> 4.3.2 is when functionality stopped working.

Using latest version of mimeDecode.php downloaded from PEAR in last couple of days.

Reproduce code:
---------------
<?php
require_once('/usr/share/pear/Mail.php');
require_once('/usr/share/pear/Mail/mimeDecode.php');

$stdin = fopen('php://stdin','r');
if( !$stdin ) {
echo 'ERROR: Cannot open stdin';
exit();
}

$msg = fread($stdin,1000000);

fclose($stdin);

$params['include_bodies'] = TRUE;
$params['decode_bodies'] = TRUE;
$params['decode_headers'] = TRUE;
$params['input'] = $msg;
$params['crlf'] = "\n";
$mail = Mail_mimeDecode::decode($params);

print_r($mail);
?>

----------------

I investigated this a bit further. The problem actually arises from the sample PHP code that is provided:#

If:
---
$msg = fread($stdin,1000000);

is replaced by:
---------------
$msg = "";
while (!feof($stdin)) {
$msg .= fread($msg, 1000000);
}

the problem does not occur anymore. In fact, as the read buffer in the example provided is only 1MB and the attachment is larger than that the email is read only partially. The Pear Manual that provided the sample code should probably be edited to include this detail...

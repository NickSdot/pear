http://pear.php.net/manual/en/package.webservices.xml-rpc.api.php

Under the heading "XML_RPC_Server", the second example:

function foo ($params) {
global $xmlrpcerruser; // import user errcode value

$xmlrpcerruser does not exist. the appropriate variable is defined on line 80 of 'XML/RPC.php'. This should read:

function foo ($params) {
global $XML_RPC_erruser; // import user errcode value

Also, in the same example, there is the comment:

// $params is an Array of XML_RPC_Value objects

Params is actually the received XML_RPC_Message object.

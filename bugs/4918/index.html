Description:
------------
Net::POP3 allows to define the preferred authentication method from the set of 'CRAM-MD5', 'APOP' , 'PLAIN' , 'LOGIN', and 'USER'.

It would be useful (at least for us:-) to extend the Auth POP3 container to accept an optional third parameter, $method, and use it as:
$result = $pop3->login($username, $password, $method);

That way, the developer is allowed to choose the preferred POP3 authentication method for his/her environment.

Currently, the default method of Net::POP3 is APOP, which is not supported by all POP3 servers. PEAR::Auth does not pass a method and thus, Net::POP3 tries APOP. In our environment, the POP3 server (qmail) closes the connection. So, the fall back method of 'USER' in Net::POP3 is not tried. Thus, we cannot use the POP3 Container :-( )

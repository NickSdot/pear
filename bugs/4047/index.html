After upgrading from Auth_HTTP 2.1.4 to 2.1.5, all applications using Auth_HTTP fails with the following error:
Parse error: parse error in /usr/share/pear/Auth/HTTP.php on line 247

The reason for this error is a missing ")" on line 247.

This patch fixes this error:
--- HTTP.php.orig 2005-04-04 08:04:52.000000000 +0200
+++ HTTP.php 2005-04-04 08:04:11.000000000 +0200
@@ -244,7 +244,7 @@
$this->password = '';

strpos($this->server['PHP_AUTH_DIGEST'],' ')+1);

Description:
------------
When you have in hierselect html entities like °. When it is this in default, displaying is OK, but if you can choose it, from hierselect menu, you can see the code of html entities (like &deg;).

Test script:
---------------
<?php
require_once 'HTML/QuickForm.php';
$form = new HTML_QuickForm('example');

$select1[0] = '';
$select1[1] = 'Temperature';
$select1[2] = 'Ratio';
// second select
$select2[0][0] = '';
$select2[1][0] = '°C';
$select2[1][1] = '°F';
$select2[1][2] = '°R';
$select2[2][0] = '1';
$select2[2][1] = '%';
$select2[2][2] = '‰';

// Create the Element
$sel =& $form->addElement('hierselect', 'choose', 'Choose Units:');

// And add the selection options
$sel->setOptions(array($select1, $select2));

$form->display();
?>

Expected result:
----------------
correct display of html entities.

Actual result:
--------------
html entities in select form (in Mozilla/5.0 (X11; U; Linux i686; en-US; rv:1.7.12) Gecko/20051013 Firefox/1.0.7).

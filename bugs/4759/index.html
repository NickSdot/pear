Description:
------------
When we use the '$' before any template variable several characters are cut out of the display. This is particularly harmful when a price is being displayed.

Reproduce code:
---------------
logic file:
$tpl->setVariable("price", "85.00");

template file:
the price is ${price}

Expected result:
----------------
the price is $85.00

Actual result:
--------------
the price is .00

In SOAP_WSDL_Cache::_cacheDir() it gets the WSDLCACHE based on $dir = getenv("WSDLCACHE"); Can this be changed to $dir = $_ENV["WSDLCACHE"]; As this would allow the location of cache to be controlled programitcally.

As currently if you do:
$_SERVER["WSDLCACHE"]='/tmp/wsdlcache';
$_ENV["WSDLCACHE"]='/tmp/wsdlcache';

echo getenv("WSDLCACHE");
phpinfo();
exit();

You will see only the PHPINFO.

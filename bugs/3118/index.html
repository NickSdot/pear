Description:
------------
Incorrect result from hasAcceptType.
I haven't tested other browser attributes but I would expect a similar problem to exist.

Reproduce code:
---------------
require_once("Net\UserAgent\Detect.php");

$dtc = new Net_UserAgent_Detect($_SERVER["HTTP_USER_AGENT"], NET_USERAGENT_DETECT_ALL);

echo $dtc->getBrowserString();
echo '<br />';
echo $dtc->getOSString();

print_r($dtc->_getStaticProperty('language'));
echo '<br />';
echo "Has EN: ".($dtc->hasAcceptType("en ","language")==true?"Yes":"No");
echo '<br />';

Expected result:
----------------
Mozilla/Netscape 6.x
Microsoft Windows XP
Array ( [en] => 1 [en-us] => 1 )
Has EN: Yes

Actual result:
--------------
Mozilla/Netscape 6.x
Microsoft Windows XP
Array ( [en] => 1 [en-us] => 1 )
Has EN: No

Description:

The function Image_Graph_Dataset::addPoint does not use its ID parameter when it calls the parent class function:

function addPoint($y, $ID = false)
{
parent::addPoint($this->count(), $y);
}

should be:

function addPoint($y, $ID = false)
{
parent::addPoint($this->count(), $y, $ID);
}

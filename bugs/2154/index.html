Description:
------------
When the server's response "realm" isn't contained in challange, Auth_SASL_DigestMD5() doesn't work on Windows platforms.

It should not use posix_uname().
This function is not available on Windows platforms.

DigestMD5.php line 129
// Realm
if (empty($tokens['realm'])) {
$uname = posix_uname(); <--- this function is problem.
^^^^^^^^^^^^^
$tokens['realm'] = $uname['nodename'];
}

e.g. Communigate PRO's challange doesn't contain 'realm'.

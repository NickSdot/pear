An url as http://www.hund.de/ should be ok, but return false

Test script:
---------------

var_dump(Validate::uri("http://www.hund.de"));
var_dump(Validate::uri("http://www.hund.de/"));
var_dump(Validate::uri("http://www.hund.de/index.html"));
var_dump(Validate::uri("http://www.hund.de/test/"));

Expected result:
----------------
bool(true) bool(true) bool(true) bool(true)

Actual result:
--------------
bool(true) bool(false) bool(true) bool(true)

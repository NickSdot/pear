Description:
------------
The package Net_DNS returns invalid IPv6 addresses if they contain
multiple 0: sequences. The compression seems to compress every 0:
sequence. But it is only allowed to compress one seqence.

The resulting ip address for kite-www.ripe.net is 2001:610:24::a843::8,
which is wrong. (It contains two times "::"!)
The original address is: 2001:610:240:0:a843::8

Reproduce code:
---------------
$ndr = new Net_DNS_Resolver();
$res = $ndr->search("kite-www.ripe.net","AAAA");
var_dump($res);

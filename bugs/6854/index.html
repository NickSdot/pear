Description:

in class Mail.php, PEAR didnot encodes spaces in mail subject into =20 sequence. it is not under RFC, so some email clients didnot show subject good.
it affect for example emails which are encoded in ISO-8859-2 encoding.

I have made small modification,it is on line 158, on file Mail.php in PEAR root folder, in function prepareHeaders():

if( $key == 'Subject' )
{
$value = str_replace( ' ', '=20', $value );
}

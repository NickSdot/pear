Description:
------------
I am using DB_DataObject_FormBuilder

@version $Id: FormBuilder.php,v 1.25 2004/05/15 22:31:15 mw21st Exp $

When function &_createDateElement() is called from &_generateForm() is does not actually modify $formValues (used to ->setDefaults()) while it should (line 626)

Reproduce code:
---------------
My solution is to add a second parameter to &_createDateElement()

function &_createDateElement($name, &$formValues)

and pass it evry time the function is called: lines 482, 501, 504:

$element =& $this->_createDateElement($key, $formValues);

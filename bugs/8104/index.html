This isn't a coding issue, but this was the method prescribed from the documentation page.

On the 'Function Definitons' page in 'Coding Standards', it states that function definitions are to use Whitesmith indentation, where such is as the following:

function fooFunction($arg1, $arg2 = '')
{
if (condition) {
statement;
}
return $val;
}

This is however, the Allman style. Whitesmith style, is:

function test(a, b)
{

call1();

}

The difference is the spacing in the principle indents.

I might be wrong. In that case, I am just requesting clarification. References follow below.

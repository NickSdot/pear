Description:
------------
DB_QueryTool is not ready to work with $primaryCol other
than "INT" because of brackets.

Reproduce code:
---------------
$primaryCol = "username";
.......

$data = array(
'username' => "'aaa'",
'password' => "bbb"
);
$authTable->update($data);

Expected result:
----------------
SELECT auth.username AS "username",auth.password AS
"password" FROM auth WHERE auth.username='aaa'
UPDATE auth SET
username='aaa',password='bbb)' WHERE
username='aaa'

similar with ->add then it produce "WHERE username=aaa"
instead "WHERE username='aaa'"

Actual result:
--------------
SELECT auth.username AS "username",auth.password AS
"password" FROM auth WHERE auth.username='aaa'
UPDATE auth SET
username='\'aaa\'',password='bbb)' WHERE
username='aaa'

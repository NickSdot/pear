Description:
------------
If you encode this url:
http://www.fçoo.com/bar.html?stuff=aa
you get this:
http://www.xn--foo-2la.com/bar.html?stuff=aa

But, if you want decode this encoded url you lost "?":
http://www.fçoo.com/bar.htmlstuff=aa

Test script:
---------------
<form name="formname" method="post" action="<?php echo $_SERVER['PHP_SELF']; ?>">
<p>
URL<br />
<input type="text" name="url" value="" size="100" />
<input type="submit" name="encode" value="Encode" />
<input type="submit" name="decode" value="Decode" />
</p>
</form>
<?php
if($_POST['encode'] || $_POST['decode']) {
require_once('IDNA.php');
$oUrl = Net_IDNA::getInstance();
if($_POST['encode']) {
echo "<p>ENCODE: | ".$oUrl->encode($_POST['url'])." |</p>";
}
if($_POST['decode']) {
echo "<p>DECODE: | ".$oUrl->decode($_POST['url'])." |</p>";
}
}
?>

Description:
------------
the function _addMapTag($shape, $coords, $params) contains a check for double quotes when generating the image map.

The check (which returns true even if no double quotes are used) is:

if (strpos($value, '"') >= 0) {
$tags .= $key . '=\'' . $value . '\'';
} else {
$tags .= $key . '="' . $value . '"';
}

Test script:
---------------
the fix is:

if (strpos($value, '"') === false) {
$tags .= $key . '="' . $value . '"';
} else {
$tags .= $key . '=\'' . $value . '\'';
}

Expected result:
----------------

<area shape="circle" coords="75,72,2" href="#test" target="_blank" alt="test" title="test">

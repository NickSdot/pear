Description:
------------
The member function escape()escape semi-colons and commas but it doesn't escape colons.
Excerpt from RFC 2426:
In addition, any COMMA character (ASCII decimal 44),
SEMI-COLON character (ASCII decimal 59) and COLON character (ASCII
decimal 58) MUST be escaped with the BACKSLASH character (ASCII
decimal 92).

Reproduce code:
---------------
$string="A;A,A:A";
Contact_Vcard_Build::escape($string);
echo $string;

Expected result:
----------------
A\;A\,A\:A

Actual result:
--------------
A\;A\,A:A

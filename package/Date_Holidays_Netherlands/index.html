Home » Date and Time » Date_Holidays_Netherlands

Driver based class to calculate holidays in the Netherlands.

Download latest release 0.1.4 (archived versions might be outdated)

Description

Date_Holidays helps you calculate the dates and titles of holidays and other special celebrations. This is the driver for calculating holidays in the Netherlands.

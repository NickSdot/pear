Validation class for Hungary

Download latest release 0.1.1 (archived versions might be outdated)

Description

This class provides methods to validate:
- Postal code (H-7090, 7090)
- Identity card (123456AA, AA123456)
- Tax number
- Bank account number
- SSN number (TAJ szam)

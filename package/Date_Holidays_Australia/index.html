Home » Date and Time » Date_Holidays_Australia

Driver based class to calculate holidays in Australia.

Download latest release 0.2.2 (archived versions might be outdated)

License: BSD

Description

Date_Holidays helps you calculate the dates and titles of holidays and other special celebrations. This is the driver for calculating holidays in Australia.

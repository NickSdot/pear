Home » Validate » Validate_IN

Validation class for the Republic of India

This package is unmaintained.

Download latest release 0.1.1 (archived versions might be outdated)

License: LGPL Version 2.1

Description

Contains locale validation for Indian:
* Permanent Account Number (PAN and TAN)
* State and Union Territory codes
* Telephone Numbers
* Postal (Zip) Codes
* Vehicle License Plate Numbers

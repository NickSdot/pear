Home » Validate » Validate_BE

Validation class for Belgium

This package is unmaintained.

Download latest release 0.1.4 (archived versions might be outdated)

License: BSD Style

Description

Package containes locale validation for Belgium such as:
* Postal Code
* Bank Account Number
* Structured Bank Transfer message
(Nationnal transfer from an bank account to another)
* VAT
* Natitonal ID
* Identity Card Number (not ready)
* SIS CARD ID (belgian "sécurité sociale" ID)

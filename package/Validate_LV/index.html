Download latest release 1.0.0RC2 (archived versions might be outdated)

Description

Data validation class for Latvia
Provides methods to validate:
- VAT number
- Registration number
- Swift code
- Telephone number
- Person ID
- IBAN Bank account number for Latvian Banks
- Postal code
- Passport
- Person name

Home » Validate » Validate_NZ

Validation class for NZ

Download latest release 0.1.6 (archived versions might be outdated)

Description

Package containes locale validation for NZ such as:
* IRD numbers
* Regional codes
* Telephone number
* Postal code
* Bank AC
* Vehicle License Plates

Maintainers

  • Byron Adams (badams) — lead, active

Dependencies

Required

  • PEAR Installer (>= 1.4.0b1)

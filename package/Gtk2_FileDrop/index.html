Make Gtk widgets accept file drops

This package is unmaintained.

Download latest release 1.0.0 (archived versions might be outdated)

License: LGPL

Description

A class which makes it easy to make a GtkWidget accept
the dropping of files or folders

Maintainers

  • Christian Weiske (cweiske) — lead, active

Dependencies

Required

  • PHP (>= 5.1, <= 5.999.999)
  • PEAR Installer (>= 1.4.1)
  • MIME_Type (>= 1.0.0)
  • php-gtk (extension, >= 2.0.0dev)

PEAR is archived and read-only

This mirror preserves historical PEAR package releases and metadata so existing references remain available.

  • No new packages can be added.
  • No package updates will be published here.
  • The PEAR CLI and channel metadata continue to work for packages and versions already in the archive.
  • New projects should use Composer and Packagist.

Home » PEAR Website » pearweb_index

The source code for the PEAR website, informational front pages

Download latest release 1.24.0 (archived versions might be outdated)

Description

The pearweb_index package contains these files from public_html:
index.php, mirrors.php, credits.php, copyright.php, gophp5.php
about/credits.php, about/index.php, about/privacy.php
group/index.php and group/docs/*, news/*, and support/*

Apple Push Notifications Service communication

This package is unmaintained.

Download latest release 0.1.0 (archived versions might be outdated)

Description

This package provides an interface for communication with
Apple Push Notifications Service (APNS). This package allows one to send
notifications to registered devices, as well as receiving users feedback
through Apple's gateway.

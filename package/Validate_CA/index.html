Home » Validate » Validate_CA

Validation class for Canada

Download latest release 0.2.0 (archived versions might be outdated)

Description

Package contains locale validation for Canada such as:
* Social Insurance Numbers (SIN)
* Postal Codes
* Regions (Provinces)
* Phone Numbers

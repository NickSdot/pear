Logging Framework

Download latest release 1.14.6 (there might be newer Composer installable version)

Description

The Log package provides an abstracted logging framework. It includes output handlers for log files, databases, syslog, email, Firebug, and the console. It also provides composite and subject-observer logging mechanisms.

Maintainers

  • Jon Parise (jon) — lead, active
  • Chuck Hagenbuch (chagenbu) — lead, active
  • Jan Schneider (yunosh) — lead, active

Dependencies

Required

  • PHP (>= 7.4.0)
  • PEAR Installer (>= 1.4.3)

Optional

  • DB (>= 1.3)
  • MDB2 (>= 2.0.0RC1)
  • Mail
  • sqlite (extension)

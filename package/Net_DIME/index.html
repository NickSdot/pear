The Net_DIME package implements DIME encoding and decoding

This package is unmaintained.

Download latest release 1.0.2 (archived versions might be outdated)

Description

The Net_DIME package provides an implementation of DIME as defined at http://xml.coverpages.org/draft-nielsen-dime-02.txt

Home » Date and Time » Date_Holidays_Spain

Driver based class to calculate holidays in Spain.

Download latest release 0.1.4 (archived versions might be outdated)

License: LGPL

Description

Date_Holidays helps you calculate the dates and titles of holidays and other special celebrations. This is the driver for calculating holidays in Spain; with thanks to Jesús Espino.

Maintainers

  • Ken Guest (kguest) — lead, active
  • Jesús Espino (jespino) — lead, active

Dependencies

Required

  • PEAR Installer (>= 1.4.0b1)
  • Date_Holidays (>= 0.21.1)

Home » HTML » HTML_QuickForm_CAPTCHA

Drop-in CAPTCHA element for QuickForm forms

Download latest release 0.3.0 (archived versions might be outdated)

Description

This package provides QuickForm interface to the Text_CAPTCHA package. It requires the use of a session to serialize a Text_CAPTCHA instance. Currently drivers for Image, Equation, Figlet and Word are included.

Maintainers

  • Philippe Jausions (jausions) — lead, active

Dependencies

Required

  • PHP (>= 4.3.0)
  • PEAR Installer (>= 1.7.1)
  • Text_CAPTCHA (>= 0.3.1)
  • HTML_QuickForm (>= 3.2.7)

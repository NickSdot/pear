Validation class for Denmark

This package is unmaintained.

Download latest release 0.2.0 (archived versions might be outdated)

License: BSD Style

Description

Package containes locale validation for Denmark such as:
* Postal Code
* Social Security Number (CPR Nummer)
* Phone number
* Car Registration number

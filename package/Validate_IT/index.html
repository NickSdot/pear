Home » Validate » Validate_IT

Validation class for Italy

This package is unmaintained.

Download latest release 0.2.0 (archived versions might be outdated)

Description

This class provides methods to validate:
* Postal code (CAP)
* Telephone number (and prefix)
* Mobile number (and prefix)
* Regions (and regions code)
* Cities (and cities code)
* Fiscal code
* Value Added Tax Identification Number (VATIN) (Partita IVA)
* Driver license

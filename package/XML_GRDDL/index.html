Home » Semantic Web » XML_GRDDL

A PHP library for dealing with GRDDL.

This package is unmaintained.

Download latest release 0.2.0 (archived versions might be outdated)

Description

Features

* Different XSLT engines can be used
* Merging of RDF results, as per spec
* Pretty close to passing GRDDL test suite tests

Maintainers

  • Daniel O'Connor (doconnor) — lead, active

Dependencies

Required

  • PHP (>= 5.2.6)
  • PEAR Installer (>= 1.4.0)
  • HTTP_Request2
  • Net_URL2
  • Log
  • Validate
  • xsl (extension)
  • tidy (extension)

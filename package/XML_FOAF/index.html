Home » XML » XML_FOAF

Provides the ability to manipulate FOAF RDF/XML

Download latest release 0.4.0 (archived versions might be outdated)

Description

XML_FOAF Allows advanced creation and simple parsing of FOAF RDF/XML files.
The FOAF Project can be found at http://www.foaf-project.org -

Home » Structures » Structures_DataGrid_Renderer_Flexy

Renderer driver using Flexy

This package is unmaintained.

Download latest release 0.1.4 (archived versions might be outdated)

License: PHP License

Description

This is a Renderer driver for Structures_DataGrid using HTML_Template_Flexy. It adds a
couple of variables to a Flexy instance and adds paging functionality. This renderer also enables customised result messages, customised column labels and a column label formatter.

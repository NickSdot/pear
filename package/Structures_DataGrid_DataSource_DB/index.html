DataSource driver using PEAR::DB result objects

Download latest release 0.1.1 (archived versions might be outdated)

Description

This is a DataSource driver for Structures_DataGrid using PEAR::DB result
objects.
Please note that this driver is deprecated. Consider using DBQuery or MDB2
DataSource drivers instead.

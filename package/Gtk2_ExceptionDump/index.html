Home » Gtk2 Components » Gtk2_ExceptionDump

Analyze exceptions, php and PEAR errors visually

This package is unmaintained.

Download latest release 1.1.1 (archived versions might be outdated)

Description

Displays Exceptions, PHP Erros and PEAR_Error objects in a nice
and clean way. It also allows to inspect parameters passed to
methods and to drag and drop the files causing the error to any
editor. Copying a string representation of the exception
to clipboard is also supported.

Maintainers

  • Christian Weiske (cweiske) — lead, active

Dependencies

Required

  • PEAR Installer (>= 1.4.8)
  • Gtk2_VarDump (>= 1.0.0)
  • php-gtk (extension, >= 2.0.1)

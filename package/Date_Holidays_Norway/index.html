Home » Date and Time » Date_Holidays_Norway

Driver based class to calculate holidays in Norway.

Download latest release 0.1.2 (archived versions might be outdated)

Description

Date_Holidays helps you calculate the dates and titles of holidays and other special celebrations. This is the driver for calculating holidays in Norway.

Create and manage sitemap files.

This package is unmaintained.

Download latest release 0.1.4 (archived versions might be outdated)

Description

This package allow to create sitemap files used to describe your
website to help search engines indexing it. This package contains all needed
functions to create, read, save, add, modify and remove url, compress to
gzip, notify search engine and test url in the sitemap or sitemap index.

Maintainers

  • Charles Brunet (cbrunet) — lead, active

Dependencies

Required

  • PHP (>= 5.0.0)
  • PEAR Installer (>= 1.4.0b1)
  • zlib (extension)
  • dom (extension)

Optional

  • HTTP_Request
  • PHPUnit (pear.phpunit.de, >= 3.6.0)

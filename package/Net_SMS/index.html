SMS functionality.

This package is unmaintained.

Download latest release 0.2.1 (archived versions might be outdated)

License: LGPL

Description

This package provides SMS functionality and access to SMS gateways.

Maintainers

  • Marko Djukic (mdjukic) — lead, active
  • Jan Schneider (yunosh) — lead, active
  • Chuck Hagenbuch (chagenbu) — lead, active

Dependencies

Required

  • PHP (>= 5.2.0)
  • PEAR Installer (>= 1.5.6)
  • gettext (extension)

Optional

  • HTTP_Request2
  • Mail
  • Net_SMPP_Client (>= 0.4.1)

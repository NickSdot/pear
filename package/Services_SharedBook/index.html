PHP wrapper for SharedBook Open API

This package is unmaintained.

Download latest release 0.2.6 (archived versions might be outdated)

License: LGPL

Description

SharedBook has developed a unique, on demand reverse publishing platform to help businesses and consumers extract, manipulate and publish the Internet content. SharedBook now has an Open API (Application Programming Interface). Now anyone can write a program that will transfer data to the SharedBook platform and utilize our full functionality to create revenue-producing books, both online and off. This package is a wrapper for Open API calls, handles XML responses, file uploads.

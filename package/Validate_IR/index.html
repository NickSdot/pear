Home » Validate » Validate_IR

Data validation class for Iran.

Download latest release 0.1.0 (archived versions might be outdated)

Description

Package containes locale validation for IR such as:
* Phone Number
* Mobile Number
* Postal Code
* SSN (This is called "Code Melli" in Iran)
* Persian Digits
* Persian alphaNumeric
* Iranian credit card

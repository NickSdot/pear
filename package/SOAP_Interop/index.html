SOAP Interop Test Application

Download latest release 0.8.2 (archived versions might be outdated)

Description

Test harness for SOAP Builders tests.
Supports Round 2 and Round 3 tests.

Maintainers

  • Jan Schneider (yunosh) — lead, active
  • Shane Caraveo (shane) — lead, active

Dependencies

Required

  • PHP (>= 4.0.0)
  • PEAR Installer (>= 1.4.0b1)
  • SOAP

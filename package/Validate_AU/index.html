Home » Validate » Validate_AU

Data validation class for Australia.

Download latest release 0.1.4 (archived versions might be outdated)

Description

Package containes locale validation for AU such as:
* Phone Number
* Postal Code
* Tax File Number
* Australian Business Number
* Australian Company Number
* Australian Regional Codes

Location of system folders

This package is unmaintained.

Download latest release 1.0.5 (archived versions might be outdated)

Description

Calculates or guesses the location of system folders like temp, desktop
and others.

Maintainers

  • Christian Weiske (cweiske) — lead, active

Dependencies

Required

  • PHP (>= 4.2, <= 6.0.0)
  • PEAR Installer (>= 1.4.1)
  • Config (>= 1.10.5)

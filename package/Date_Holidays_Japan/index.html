Home » Date and Time » Date_Holidays_Japan

Driver based class to calculate holidays in Japan.

Download latest release 0.1.3 (archived versions might be outdated)

License: BSD

Description

Date_Holidays helps you calculate the dates and titles of holidays and other special celebrations. This is the driver for calculating holidays in Japan.

Maintainers

  • Hideyuki Shimooka (hshimooka) — helper, active

Dependencies

  • PEAR Installer (>= 1.4.0b1)

go-pear script for pear.php.net

This package is unmaintained.

Download latest release 1.1.7 (archived versions might be outdated)

Description

go-pear is the online PEAR installer: just download it and run it (through a browser or command line), it will set up a minimal PEAR installation that will be ready for immediatel use.

You can download go-pear from http://pear.php.net/go-pear
(this is merely the pearweb package hosting it)

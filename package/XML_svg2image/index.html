Home » XML » XML_svg2image

Converts a svg file to a png/jpeg image

Download latest release 0.2.0 (archived versions might be outdated)

Description

Converts a svg file to a png/jpeg image with the help of apache-batik
(java-program), needs therefore a php with ext/java compiled-in and
the batik files from http://xml.apache.org/batik

Maintainers

  • Christian Stocker (chregu) — lead, active

Dependencies

  • PEAR Installer (>= 1.5.6)

Optional

Some small classes to handle common <select> lists

This package is unmaintained.

Download latest release 1.2.0 (archived versions might be outdated)

Description

Provides <select>lists for:
o Country
o UK counties
o US States
o FR Departements
o NO Fylke
o NO Kommuner
o ptBR
